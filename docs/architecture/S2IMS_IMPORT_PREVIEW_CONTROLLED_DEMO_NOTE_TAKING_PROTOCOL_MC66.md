# S2IMS Import Preview Controlled Demo Note-taking Protocol — MC66

## Purpose
Provide a standard protocol for note-takers during controlled internal demo sessions to ensure safety, consistency, and privacy.

## Allowed notes
- UX observations (copy, layout)
- Validation behavior descriptions (what messages appear)
- Accessibility observations
- Suggestions and questions (no PII)

## Forbidden notes
- Direct reproduction of any PII observed
- Approval or sign-off wording
- Confirmation that data was persisted

## No PII rule
- If any PII is observed, stop the session, delete local artifacts, notify security

## Feedback categories and severity
- Use MC65 feedback themes and severity model

## Governance-sensitive marking
- Prepend "[GOV]" to entries that are governance-sensitive

## Post-session storage rule
- Store notes in external evidence store if required; do NOT commit to repo

## MC67 reporting rule
- Note-takers must hand over captured notes to MC67 compiler when session actually occurs
