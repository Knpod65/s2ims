# S2IMS Import Preview Controlled Demo Feedback Worksheet — MC67

## Purpose
Provide a feedback worksheet for participants to record planning feedback during a controlled internal demo walkthrough. This is a planning-only template; do not include PII or commit worksheets to the repository.

## Instructions
- Use one row per feedback item
- Do not include any PII in feedback_summary_no_pii
- Mark governance_sensitive as yes/no
- Use severity levels: Low, Medium, High, Blocked
- Store any screenshots externally and reference by path

## Governance-sensitive handling

## Examples of safe feedback
- "Validation message for missing email is unclear to non-technical users."
- "Keyboard focus does not reach the mapping dialog."

## Examples of unsafe feedback (do not record)
- "Student S-12345 appears with email alice@example.edu" (contains PII)
- "This proves data was persisted" (may be incorrect and dangerous)

## No approval/signoff reminder
- This worksheet is for planning feedback only and is not an approval document.

## Post-session handling
- Collate entries into MC68 execution report only if the controlled demo session actually occurs and a user authorises creation of that report.
